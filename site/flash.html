USB · No install · No driver

Flash it from your browser.

No PlatformIO, no cable-driver hunt. Plug the X4 in over USB, click once, pick the port your browser shows you, and it's installed. The X4's chip talks native USB, so there's no CP2102/CH340 driver step either — the thing that usually trips people up with ESP32 boards.

Your browser can't do this — Web Serial needs desktop Chrome or Edge (not Safari, not Firefox, not mobile). Use the command-line install instead. This needs to be served over HTTPS to work — if you're reading this on shelbeeely.github.io, that's already true, so try reloading.

Installing replaces everything currently on the chip. If the board is already set up and you just want a newer build, use the settings portal's Firmware step instead (OTA update docs) — it's faster and doesn't need a cable at all once a board has ever had one plugged in.

  • ✓ Browser: Chrome or Edge, on a laptop or desktop — Web Serial isn't available on iOS/Android or in Safari/Firefox.
  • ✓ Cable: a USB-C data cable (not a charge-only one) to the X4's own port — no separate USB-serial adapter needed.
  • ! First board only: after this first flash, every later update can go over the air — see Setup for what happens next.

What happens

Three steps, about a minute

1

Plug in & connect

Click "Connect & flash," then pick the X4 from the browser's own port picker — there's exactly one device to choose since nothing else is plugged in.

2

Install

The page writes the bootloader, partition table, and firmware straight to flash and shows a progress bar. Don't unplug the cable or close the tab until it says done.

3

Set it up

The board reboots into first-run setup — its own Wi-Fi access point and a captive-portal page, same as buying one pre-flashed. See Setup for that walkthrough.

Alternative

Prefer the command line?

Nothing above is required — building and flashing with PlatformIO works exactly as it always has, and is the only option for the bringup/debug build. See Build it on the main page.
